DRIVING QUIZ PRACTICE

1. Extract the ZIP folder.
2. Double-click index.html to open it in Chrome, Edge, Firefox, or Safari.
3. No installation and no internet connection are required.

The quiz contains all 335 supplied questions: 236 written questions and 99 road-sign questions. Questions are grouped by topic so similar questions appear consecutively. It includes all road-sign images, automatic progress saving, a question-number selector, live correct/incorrect counters, instant answer feedback, final score, mistake review, restart, mobile layout, and keyboard shortcuts (1/2/3 for answers, Enter to confirm/continue).
